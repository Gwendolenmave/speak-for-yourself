# Contributing

**This project is under closed maintenance.** It is not accepting substantive external code contributions, and pull requests are not part of the canonical maintenance workflow.

That is a deliberate maintenance model, not a temporary backlog.

## What is welcome

- **Bug reports**, especially reproducible cases where Text / Voice / Both resolves or delivers incorrectly.
- **Compatibility reports** for agent frameworks, providers, Node.js versions, Telegram, or ElevenLabs.
- **Architecture questions and disagreement** grounded in a concrete invariant, test, or failure mode.
- **Documentation corrections** that contain no private runtime material.
- **Security reports**, sent privately according to `SECURITY.md`.

Do not attach real transcripts, generated private audio, credentials, provider responses, bot tokens, runtime databases, logs, backups, or machine-specific private paths to an issue. Build a synthetic reproduction instead.

## What to do instead of a pull request

Fork the repository. The licence permits noncommercial use and modification, and the project is intentionally small enough to adapt to another provider, transport, spoken language, or host runtime.

Keep the PolyForm Noncommercial terms and required notices with any noncommercial distribution. Commercial use or distribution requires a separate arrangement with the licensor.
